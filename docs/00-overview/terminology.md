# 术语约定：推断 vs 推理

> 所属：[TinyLLM Docs](../README.md) › [Overview](index.md)

本项目统一区分两个容易混淆的概念。

## 模型推断（Inference）

**定义**：训练完成的模型接收输入并产生输出的过程，包括前向计算、解码/生成、KV cache、批处理与服务化。

**推荐表述**：

- 模型推断 / 推断
- 推断阶段、推断服务、推断引擎、推断性能、推断请求
- 推断时扩展（inference-time scaling）或测试时扩展

**不要用于**：模型的多步分析、推导、验证等认知过程。

## 逻辑推理（Reasoning）

**定义**：模型在给出结论前进行的多步分析、推导、验证等认知过程，包括 CoT、self-consistency、RLVR/GRPO、推理蒸馏与推理评测。

**推荐表述**：

- 逻辑推理 / 推理
- 推理模型、推理能力、推理链、推理策略、推理任务
- 推理蒸馏、推理评测

**不要用于**：单纯的模型前向/生成/服务化过程。

## 边界案例

| 场景 | 推荐写法 | 不推荐 |
|---|---|---|
| 训练后模型生成输出 | 模型推断 | 模型推理 |
| 部署与吞吐 | 推断服务、推断性能 | 推理服务、推理性能 |
| 增加测试时计算 | 推断时扩展、测试时扩展 | 推理时扩展 |
| CoT / 多步推导 | 推理、逻辑推理 | 推断 |
| reasoning model | 推理模型 | 推断模型 |

## 代码标识符

`inference/`、`reasoning/`、`inference.py` 等英文标识符保持不变；中文说明按上述规则使用。

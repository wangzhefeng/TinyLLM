### 3.5 Chapter 5：Pretraining on Unlabeled Data

**主线内容**

- 用 `the-verdict.txt` 走通：数据集 → 交叉熵 → 训练循环 → 训练/验证损失 → 采样生成。
- 加载 OpenAI GPT-2 权重（124M/355M/774M/1558M），做继续预训练或直接生成。
- 训练曲线、学习率、梯度裁剪的直观影响。

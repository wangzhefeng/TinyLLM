### 3.1 Chapter 1：Understanding LLMs

- **内容**：LLM 的生命周期（数据 → 预训练 → SFT → 偏好对齐 → 评测）、本书路线图、阅读建议。
- **代码**：无。
- **价值**：建立“先预训练、再微调、最后对齐”的心智模型。
- **对本项目**：无需覆盖；项目 README 里已经有类似的概念索引。

### 3.2 Chapter 2：Working with Text Data

**主线内容**

- 分词的基本粒度：word / subword / character；BPE 与 Unigram 的区别。
- 特殊 token：`<|endoftext|>`、`[PAD]`、`[BOS]`、`[EOS]`、`[UNK]`。
- 用 `tiktoken` 加载 GPT-2 BPE（vocab 50257），实现 `SimpleTokenizerV1/V2`。
- 滑动窗口数据集 `GPTDatasetV1`：`max_length` + `stride`，输入/目标右移一位。
- `create_dataloader_v1`：batch size、stride、shuffle、drop_last。

**Bonus**

| 子目录 | 内容 |
|---|---|
| `02_bonus_bytepair-encoder` | 对比 tiktoken / HF tokenizers / 朴素 BPE 的速度与行为 |
| `03_bonus_embedding-vs-matmul` | 证明 Embedding 层与“one-hot × Linear”等价 |
| `04_bonus_dataloader-intuition` | 用整数序列直观解释滑动窗口与 batch |
| `05_bpe-from-scratch` | 从零实现 BPE：简化版 + 处理边界情况的完整版，可加载 GPT-2 vocab/merges，附 `tests.py` |
| `06_bonus_simple-tokenizer-v3` | 保留空白/分隔符、可往返的 `SimpleTokenizerV3` |

**学习价值**：`05_bpe-from-scratch` 是整个仓库里“最底层”的一块，理解它之后，tokenizer 不再是黑盒。

**对本项目**：`layers/tokenizers/` 已经非常丰富（simple_bpe、tiktoken、HF GPT-2、Llama 3 BPE、SentencePiece、Qwen3、Gemma、chat template、MiniMind tokenizer 训练）。缺的是：
- SimpleTokenizerV3 式的“空白往返”；
- BPE 边界情况的 parity 测试；
- 多种 BPE 实现的 benchmark。

### 3.3 Chapter 3：Coding Attention Mechanisms

**主线内容**

- 简化自注意力 `SelfAttention_v1`（手写 softmax）与 `v2`（`nn.Linear`）。
- 因果掩码、dropout、缩放点积。
- `MultiHeadAttentionWrapper`（多个头拼接）与 `MultiHeadAttention`（QKV 合并投影 + reshape/transpose）。
- 注意力权重的形状变换是本章最容易被忽略、也最容易写错的部分。

**Bonus**

| 子目录 | 内容 |
|---|---|
| `02_bonus_efficient-multihead-attention` | 5–6 种 MHA 实现对比：naive、einsum、`scaled_dot_product_attention`、FlexAttention、编译后性能 |
| `03_understanding-buffers` | 解释 `register_buffer` 与普通属性的区别（因果掩码应作为 buffer） |

**对本项目**：覆盖充分且更广。`layers/attention.py` 里有 `CausalAttention`、`MultiHeadAttentionWrapper`、`MultiHeadAttention`、`MultiHeadAttentionCombinedQKV`、`MHAEinsum`、`MHAPyTorchScaledDotProduct`、`MHAPyTorchSDPAWithoutFlash`、`MHAPyTorchFlexAttention`、`GroupedQueryAttention`、Qwen3/Gemma3 变体；`SharedBuffers` 对应 buffer 优化。

**缺口**：没有把“多种 MHA 实现的 benchmark”整理成可复现实验（仓库有 notebook，项目只有零散测试）。
